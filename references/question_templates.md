# 题型模板与出题规范

## 一、题型分类与适用场景

| 题型 | 考察维度 | 适用场景 | 建议占比 |
|------|----------|----------|----------|
| 单选题 | 知识记忆、概念辨析 | 基础知识考核 | 30-40% |
| 多选题 | 综合理解、知识关联 | 中级知识考核 | 15-20% |
| 判断题 | 概念准确性 | 快速检测 | 10-15% |
| 简答题 | 逻辑表达、深度理解 | 高阶知识考核 | 15-20% |
| 实操题 | 技能应用、问题解决 | 技能考核 | 15-25% |

## 二、出题规范

### 单选题
1. 题干表述清晰，无歧义
2. 4个选项，只有1个正确答案
3. 干扰项具有合理性，不出现明显错误
4. 选项长度大致相当
5. 避免使用"以上都是"/"以上都不是"

**模板：**
```
[题干]：关于______，以下说法正确的是？
A. [干扰项1 - 常见误解]
B. [正确答案]
C. [干扰项2 - 部分正确]
D. [干扰项3 - 过于绝对]
```

### 多选题
1. 2-5个正确选项
2. 明确标注"多选"或"至少选两项"
3. 部分正确不得分或半分
4. 各选项独立，不相互包含

**模板：**
```
[题干]：以下哪些是______的正确做法？（多选）
A. [正确项1]
B. [正确项2]
C. [干扰项 - 看似合理但不完全]
D. [正确项3]
```

### 判断题
1. 表述明确，不含模棱两可的词
2. 避免双重否定
3. 避免绝对化表述（"必须"、"一定"等）

**模板：**
```
[判断]：______的说法是否正确？
对 / 错
解析：[说明为什么对或错]
```

### 简答题
1. 问题指向明确，不泛泛而问
2. 给出答题要点和字数参考
3. 评分标准清晰（按要点给分）

**模板：**
```
[题目]：请简述______的实现步骤和注意事项。
答题要点：
1. [要点1]（X分）
2. [要点2]（X分）
3. [要点3]（X分）
评分标准：每个要点完整表述得满分，部分表述得半分
```

### 实操题
1. 明确操作目标和验收标准
2. 给出必要的环境信息和前提条件
3. 步骤可验证、结果可检查

**模板：**
```
[题目]：请在______环境中完成以下操作：
1. [操作要求1]
2. [操作要求2]
3. [操作要求3]

验收标准：
- [标准1]：[分值]
- [标准2]：[分值]
- [标准3]：[分值]

预期输出/结果：[描述]
```

## 三、难度分级标准

### 基础级（40%）
- 直接考查概念和定义
- 书本上可找到答案
- 不需要综合分析

### 中级（40%）
- 需要理解概念之间的关系
- 需要简单推理和分析
- 结合实际场景

### 高级（20%）
- 需要综合运用多个知识点
- 需要创造性解决问题
- 超出教材范围的延伸

## 四、题目质量检查清单

- [ ] 题干是否表述清晰无歧义
- [ ] 答案是否唯一且正确
- [ ] 干扰项是否具有合理性
- [ ] 难度分布是否符合设计
- [ ] 知识点覆盖是否全面
- [ ] 是否存在题目间互相提示
- [ ] 用语是否符合目标学员认知水平
- [ ] 解析是否充分说明原因
