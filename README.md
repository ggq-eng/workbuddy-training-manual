WorkBuddy

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/workbuddy-training-manual        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/workbuddy-training-manual   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
